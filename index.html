Application information

A private reservation workflow.

Airspace Reservations is an internal tool for coordinating museum entry-pass reservations and operational email reports.

This website provides application and privacy information. It does not accept reservations, provide a public sign-in service, or request access to visitors’ Google accounts.

What the application does

The tool assists its operator with museum reservation workflows. Google account access is used to retrieve account-verification emails, check relevant reservation confirmations when needed, and send operational reports and alerts.

Access is limited to an operator-authorized Google account. Reservation execution is controlled separately from this informational website.

Why Gmail access is requested

  • Read-only access: to locate new verification emails and read the verification code needed to sign in to the reservation account. The permission also supports checking reservation-confirmation messages.
  • Send access: to send test reports, reservation summaries, and failure alerts to the configured operator address.

These permissions do not grant the application permission to delete or modify existing email messages. Read-only permission technically covers the entire mailbox; application logic selects messages relevant to the workflow.

Control and privacy

The account owner grants access through Google’s authorization screen and can revoke it through Google Account settings. The application does not collect a Google password.

Read the Privacy Policy for details about data handling, service providers, retention, and revoking access.
